# EventSphere — как проверить MVP

**Приложение:** https://eventsphere-self.vercel.app
**Код:** https://github.com/AmanTugolbekov/SkillabAi

Открывается в браузере на телефоне и на компьютере, ставить ничего не нужно.

## Аккаунты

Можно зарегистрироваться своей почтой или войти через Google. Для быстрой
проверки есть готовые — пароль у всех `eventsphere`:

| Почта | Кто |
|---|---|
| `amina@example.kg` | участница, 22 года |
| `timur@example.kg` | родитель, двое детей |
| `admin@example.kg` | модератор документов |

Экран модерации доступен только последнему: у обычных аккаунтов его нет.

## Проверка MVP

1. **Афиша** — полоса дат переключает день, фильтры по району, цене и
   возрасту работают сразу.
2. **Запись.** Войдите как `amina@example.kg`, откройте любое бесплатное
   событие и нажмите «Записаться» — счётчик мест изменится.
3. **Проверка организаторов.** Откройте платное событие организатора
   «Данияр А.» — запись закрыта, он не подтвердил личность. То же правило не
   даёт ему опубликовать платное событие.
4. **Родительский контроль.** Войдите как `timur@example.kg` → «Записи».
   Там заявка Бекзата на шахматный турнир: ребёнок записался сам, место за
   ним не закреплено, пока родитель не нажмёт «Разрешить».
5. **Верификация.** Войдите как `admin@example.kg` → «Профиль» → «Модерация
   организаторов» → подтвердите заявку Trail KG. После этого его платные
   события открываются для записи.

## Проверка AI

AI отвечает за две задачи.

**1. Поиск обычными словами** — вкладка «Спросить».

Введите: `Найди IT-встречу за городом на эти выходные`

Ассистент разложит запрос в фильтры (район «За городом», ближайшие суббота и
воскресенье) и покажет под ответом, как именно он его понял. Ответ занимает
5–10 секунд.

Ещё примеры: `Языковой клуб в центре до 500 сом`,
`Что есть для ребёнка 10 лет в субботу`.

**2. Разбор анонса организатора** — «Я организатор» → «Создать» → «вставить
пример» → «Структурировать с AI».

На входе сплошной текст: «Народ, в эту субботу 14 ноября собираемся на пикник
в Ботаническом саду, сбор в 13:00 у входа с Ахунбаева. Взнос 250 сом…»

На выходе заполненная форма: заголовок «Пикник в Ботаническом саду»,
написанное описание, дата `2026-11-14 13:00`, цена 250, возраст 16+, место,
программа по времени, список того, что взять, и что входит в стоимость. Все
поля редактируются.

Работает на Gemini. Если ключа нет, обе функции переключаются на встроенные
правила разбора текста — приложение не ломается, а в профиле видно, какой
движок сейчас работает.

## Локальный запуск

```bash
git clone https://github.com/AmanTugolbekov/SkillabAi.git
cd SkillabAi && npm install && npm run seed && npm run dev
```

Нужен Node 24. Переменные окружения — в `.env.example`, подробности в
`README.md`.
