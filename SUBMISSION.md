# EventSphere — как проверить проект

Единое приложение для событий Бишкека: хакатоны, клубы, воркшопы, поездки.
Две стороны в одном продукте — участник ищет и записывается, организатор
публикует и собирает людей. Две вещи делают его не просто афишей: проверка
организаторов по документу и родительский контроль для участников младше 13.

**Приложение:** https://eventsphere-self.vercel.app
**Исходный код:** https://github.com/AmanTugolbekov/SkillabAi

Открывается в браузере на телефоне и на компьютере, устанавливать ничего не
нужно. Светлая и тёмная темы переключаются кнопкой в шапке.

---

## Как войти

### Свой аккаунт

Кнопка «Войти» в шапке → «Зарегистрироваться». Нужны имя, почта, пароль от
8 символов и год рождения. Год обязателен: на нём держатся возрастные
ограничения событий.

### Через Google

На экране входа есть кнопка «Продолжить с Google». После первого входа
приложение один раз спросит год рождения — Google его не передаёт.

### Готовые аккаунты

Если регистрироваться не хочется, пароль у всех трёх — `eventsphere`:

| Почта | Кто это | Что показывает |
|---|---|---|
| `amina@example.kg` | Амина, 22 года | Обычный участник: поиск, запись, свои записи |
| `timur@example.kg` | Тимур, родитель | Двое детей, есть заявка на подтверждение |
| `sanzhar@example.kg` | Санжар, 18 лет | Второй участник, для проверки чужих записей |

## Что посмотреть, по шагам

**1. Афиша.** Полоса дат под шапкой переключает день. Фильтры по району,
цене, возрасту и «только проверенные организаторы» работают без перезагрузки
логики — это обычная форма, она жива даже без JavaScript. У событий —
фотографии настоящих мест: библиотека им. Баялинова, кинотеатр «Ала-Тоо»,
Ботанический сад, КТУ, Иссык-Куль.

**2. AI-поиск** — вкладка «Спросить». Напишите обычными словами, например
«Найди IT-встречу за городом на эти выходные» или «Языковой клуб в центре до
500 сом». Ассистент разложит запрос в фильтры и покажет, как именно он его
понял. Ответ занимает 5–10 секунд.

**3. Запись на событие.** Войдите как `amina@example.kg`, откройте любое
бесплатное событие проверенного организатора и нажмите «Записаться».
Счётчик мест меняется сразу.

**4. Проверка организаторов.** Откройте платное событие организатора
«Данияр А.» — запись закрыта, потому что он не подтвердил личность. Это не
заглушка: то же правило не даёт ему и опубликовать платное событие.

**5. Родительский контроль.** Войдите как `timur@example.kg` → вкладка
«Записи». Там висит заявка Бекзата на шахматный турнир: ребёнок записался
сам, место за ним не закреплено, пока родитель не нажмёт «Разрешить».
В профиле родителя можно добавить или удалить детский профиль — своего входа
у ребёнка нет.

**6. AI-создание события.** В шапке «Я организатор» → «Создать» → «вставить
пример» → «Структурировать с AI». Сплошной текст анонса превращается в
заголовок, описание, программу по времени, список требований, цену, даты и
возраст. Все поля остаются редактируемыми.

**7. Верификация.** Попробуйте опубликовать это событие — оно платное, и
приложение не даст, пока личность не подтверждена. Заполните проверку, затем
откройте «Профиль» → «Модерация организаторов», подтвердите заявку — и
публикация пройдёт.

## Что под капотом

Next.js 16 на TypeScript, развёрнут на Vercel. База — Turso (SQLite в облаке),
общая для всех экземпляров приложения.

Авторизация написана без внешних библиотек: пароли хешируются scrypt из
стандартной библиотеки Node, сессия хранится в подписанной куке, вход через
Google — по протоколу OAuth 2.0.

AI работает на Gemini и отвечает за две задачи: превращает сплошной текст
анонса в структуру и разбирает поисковые запросы на естественном языке. Если
ключа нет, обе функции переключаются на встроенные правила разбора текста —
приложение не ломается, а на экране профиля честно написано, какой движок
сейчас работает.

Фотографии событий — со свободными лицензиями (Викисклад, Unsplash,
Openverse), авторство указано в `public/events/CREDITS.md`.

## Запуск на своём компьютере

```bash
git clone https://github.com/AmanTugolbekov/SkillabAi.git
cd SkillabAi
npm install
npm run seed
npm run dev
```

Откроется на http://localhost:3000 с локальной базой и встроенными правилами
вместо AI. Чтобы включить облачную базу, вход через Google и Gemini, нужен
файл `.env.local` — список переменных в `.env.example`, подробности в
`README.md`.

Нужен Node 24.

## Чего в прототипе намеренно нет

**Приёма платежей.** Взносы считаются и показываются, но денег приложение не
трогает. Полурабочая оплата в демонстрации навредила бы сильнее, чем её
честное отсутствие.

**Настоящей проверки документов.** Форма верификации собирает данные и
сохраняет последние 4 цифры номера; решение принимает модератор вручную. В
рабочей версии здесь будет провайдер проверки документов.

**Отмены своей записи и редактирования опубликованного события.** Знаем, это
первое, что стоит доделать.

Следующие шаги, на которые заложена основа: приём взносов с заморозкой денег
до начала события, подбор команды на хакатон по нужным навыкам и отзывы об
организаторе после мероприятия.
